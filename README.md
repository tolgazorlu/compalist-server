## Getting Started

This is an Nodejs, Express, MongoDB project.
To get a local copy up and running follow these simple example steps.

### Prerequisites

This is an example of how to list things you need to use the software and how to install them.

-   npm
    ```sh
    npm install npm@latest -g
    ```

### Installation

_Below is an example of how you can instruct your audience on installing and setting up your app. This project doesn't rely on any external dependencies or services._

1. Clone the repo
    ```sh
    git clone https://github.com/Compalistt/compalist-backend
    ```
2. Create '.env' file in server folder. Paste this code in file.
    ```sh
    PORT=8000
    MONGO_URI=example_mongodb_url
    BASE_CLIENT_URL=http://localhost:8080
    BASE_SERVER_URL=http://localhost:3000
    TOKEN_KEY=example_jwt_key
    ```
3. Install server packages
    ```sh
    npm install
    npm run dev
    ```
